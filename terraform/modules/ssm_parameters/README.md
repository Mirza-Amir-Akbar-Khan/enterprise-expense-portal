# 🔑 AWS SSM Parameter Store Terraform Module

This module manages application configuration parameters in AWS SSM Parameter Store:

- `/enterprise-expense-app/dev/cognito_user_pool_id`: Cognito User Pool ID.
- `/enterprise-expense-app/dev/cognito_client_id`: Cognito App Client ID.
- `/enterprise-expense-app/dev/api_url`: Application Load Balancer API DNS URL.
- `/enterprise-expense-app/dev/ecr_repository_url`: ECR Repository URL.
